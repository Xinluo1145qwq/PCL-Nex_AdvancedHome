# 高级主页 · Advanced Homepage

PCL Nex 启动器插件，用 9 列自适应网格卡片替代原版主页，首个模板为「日历 + 启动热力」。

## 功能

- **卡片外壳**：复用启动器原生 `MyCard` 作为背景层（圆角/透明度/模糊/阴影与启动器一致），内容层叠在其上——`MyCard` 内部背景层是禁用命中测试的，内容必须放在兄弟层才能响应鼠标。
- **像素级版式**：卡片所有间距、字号、格子尺寸都按设计稿（内容区 315×370）等比换算，窗口缩放时留白比例不变。
- **网格主页**：横向 **9 格**，纵向行数**按组件实际堆到哪就在哪收尾**（不再固定 10 行、不留空网格）；一格高 = 1.5 格宽，所以卡片尺寸和以前一致。网格线只在「编辑布局」时显示。
- **旧布局自动迁移**：6 列的老配置按比例换算横向位置，**跨度保持不变**，组件不会被放大。
- **日历模板**：默认占 3×4 格，头部为「📅 日历 ‹ 2026年10月 ›」，点击月份标题回到今天；月份按实际周数渲染 4/5/6 行。
- **启动热力**：每启动一次游戏，当天底色加深一档，共 8 档（超过 8 次仍为第 8 档）。
- **选中与详情**：点击任意日期，底部显示「10月31日你游玩了：」与当天启动次数。
- **悬浮提示**：鼠标停在日期上显示当天启动次数。
- **未来月份灰字**：属于下个月及之后的日期使用灰色字体，不参与热力着色。
- **顶部样式条**：主页最上方是「花样 / 极简」两档开关 + 一个画笔按钮，颜色取自启动器主题色（`ColorBrush3`，与启动器按钮同色）。
  - **花样**：日历 + 启动热力上色（默认）。
  - **极简**：卡片里只显示居中的当前日期（`yyyy:MM:dd`）和一行轮播标语。
  - **画笔按钮**：进入/退出编辑布局；进入后图标变成对勾。
  - **「+」和「删除布局」只在编辑模式出现**：不编辑时顶部条只有「花样 / 极简」和画笔，主页保持干净。
- **标语轮播**：极简模式每 6 秒淡入淡出切换一条标语（可在配置里改间隔和内容，留空则用内置 12 条）。
- **编辑布局**：点顶部画笔按钮进入编辑模式（显示网格线 + 顶部提示），再点一次退出。
  - **悬停即选中**：鼠标移到卡片上就出现蓝色描边；不用先点一下。
  - **删掉的组件可以再添回来**：「已在主页」看的是当前布局，不是内存里注册过什么，所以删掉 / 清空布局之后照样能重新添加。
  - **右上角操作药丸**：选中后卡片右上角浮出一颗药丸，从左到右是「⚙ 设置」「⋯ 选项」「× 删除」。
  - **每个组件独立的设置面板**（⚙）：面板改用启动器原生控件——滑块是 `MySlider`、开关是 `MyCheckBox`、按钮是 `MyButton`，和 PCL 自己的设置页一致（问候组件仍用它原来的面板）。
    - **背景图片**：缩略图 + 「选择图片… / 清除」，铺满卡片、按卡片圆角裁切。
    - **背景透明度**：拖到 100% 是启动器原生底色，拖到 0 整张卡片（含背景图）完全透出壁纸，**拖动时卡片实时变化**。
    - 皮肤卡还能在同一个面板里换皮肤、开关三项交互。所有行共用一套栅格：标签左对齐、控件右边缘对齐。
  - **移动**：按住卡片拖到目标格子（移动超过 6px 才算拖动，单击不会误移）。
  - **缩放**：拖右下角的圆形手柄。手柄内缩 6px，圆心正好落在卡片 11px 圆角的弧心上，和圆角是同心的，不会糊在角上。
  - **删除动画**：卡片轻微缩小 + 上浮 7px 再淡出（190ms，Quintic 缓入），不会「啪」地消失。
  - **选中动画**：描边 90ms 淡入，右上角药丸从角上用 BackEase 弹出来；扫过一排卡片时不会闪。
  - **撤销**：删除单个组件不可撤销；「删除布局」删完会在**右下角弹出 6 秒 snackbar**，带进度线，点「撤销」整块布局原样回来。
  - **删除布局**：清空当前布局里的所有组件（花样 / 极简各自独立）。点击后弹出**启动器原生样式的确认框**（标题 + 主题色分隔线 + 正文 + 红色「取消」/红色「确认」/蓝色「取消」三颗按钮）。
  - **添加**：点顶部「+」圆钮，弹出**添加高级主页小组件**窗口，按「基础 / 收藏内容 / 单项快捷入口 / PCL 实用功能」四个分类挑选，加进来的卡片会自动找不重叠的空位。
- **入场动画**：从设置 / 工具等页面切回主页时，卡片按「先上后下、先左后右」的顺序错开淡入（每张 36ms、上浮 10px、260ms Quintic 缓出），不是整块瞬间出现。
- **组件**：
  - **日历**（3×4，可缩放）：月份切换、8 档热力、点日期看当天次数。卡片高度撑满网格，底边与右侧卡片对齐。
  - **最近游玩的世界**（3×4，可缩放）：扫描 `saves`（含各实例存档）里的 `level.dat`，列出存档名、上次游玩时间、版本；点右侧 ▶ 直接启动并进入该存档。
  - **最近游玩的实例**（3×4，可缩放）：扫描 `versions`，列出实例名、上次游玩时间与「加载器 + 版本」；点 ▶ 启动该实例。
    - 图标优先用启动器给实例设的 `PCL/Logo.png`；没有自定义图标的，用启动器内置的方块图标（Fabric 布卷 / NeoForge 铁砧 / 原版草方块）。
  - **问候**（3×1，可缩放，**背景透明**）：上面一行日期「11月1日星期日」，下面一句问候。
    - 选中卡片后点右上角「⋯ → 自定义问候语…」打开设置：显示方式（仅自动问候 / 文字 + 自动问候 / 仅自定义文字）、字号 16–32、自定义问候语（一行一条）、实时预览。
    - 自动问候按时段变化（凌晨 / 早晨 / 上午 / 中午 / 下午 / 晚上 / 深夜）。
    - 问候语按卡片宽度**自动缩字号**：卡片被拖窄时优先保持一行，不会折成两行压到壁纸上。
    - 自定义文字留空时自动使用内置标语（和极简模式同一套）。
  - **标语卡片**（极简样式专用）：居中日期 + 标语轮播。
  - **单项快捷入口**（默认 4×2，可缩放，可添加多个）：把某一个实例 / 存档 / 服务器 / 网站钉成一张卡片，点右下角 ▶ 直接启动。
    - **两套版式自动切换**：两行以上用「图标在左 + 竖分隔线 + 分类/标题/两行信息」的横向版；压到一行高就换成「图标在上 + 标题 + 一行副标题」的紧凑版。两种版式的水印都放在**右上角**。
    - **图标加大**：左侧的主图标（实例封面 / 存档截图 / 服务器图标）比上一版放大约三成，水印大小不变。
    - 横向版按卡片**宽度**缩放并整体垂直居中，所以卡片被拖成竖长条时字号不会被摊散、留白也不会全堆在底部。
    - 同一目标重复添加时会复用之前那条入口，配置里不会越删越多。
    - **单个实例入口**：选一个实例 → 卡片就是它的启动按钮。
    - **单个世界入口**：先选实例，再从该实例里选一个存档 → 点 ▶ 直接进入这个存档（副标题显示「创造模式 · 1.20.1」）。
    - **单个服务器入口**：先选实例，再从该实例 `servers.dat` 里（也就是游戏里加过的服务器）选一个 → 点 ▶ 直接联机。卡片会显示**实时在线人数**（Server List Ping，支持 `_minecraft._tcp` 的 SRV 解析，失败显示「离线」，60 秒缓存，后台查询不卡主页）和服务器地址。
    - 卡片图标用目标自己的图：实例取 `PCL/Logo.png` 或启动器方块图标，存档取 `saves/<存档>/icon.png`，服务器取 `servers.dat` 里存的 base64 图标。
    - **单个网站**：填名称 / 网址 / 图标 → 点 ▶ 用默认浏览器打开。
    - 选中卡片点「⋯ → 更换目标…」可以重新挑；网站卡片是「⋯ → 自定义网站…」；删除卡片时对应的配置项也会一起清掉。
  - **皮肤预览**（3×3，可缩放，**可添加任意多个**）：3D 展示一个 Minecraft 皮肤，用 Viewport3D 拼的方块模型。
    - **添加时选皮肤**：输入正版玩家名（走 Mojang API 拉贴图）、选本地 PNG，或者直接用内置的 Steve / Alex（贴图由代码绘制，不依赖外部素材），右侧实时 3D 预览。
    - **头部跟随鼠标**：鼠标在卡片里移动时，头部朝那个方向转（离开卡片自动回正）。
    - **比例对齐 NameMC**：相机 fov 50°、距离 43.8、人物居中（脚底 -16 / 头顶 +16），和 skinview3d 的默认取景一致；贴图先按最近邻放大 8 倍再上模型，是清楚的像素块而不是糊的。
    - **走动动画**：完全照 skinview3d 的 WalkingAnimation——手臂/腿各 0.5 rad 反相摆动，手臂外张 3.6°、再叠 1.7° 摆动，头部前后小幅晃动。
    - **拖动转身**：按住卡片左右拖可以绕着人物转 360°，上下拖改俯仰角（±80°），编辑布局时自动让位给卡片拖动。
    - **头部跟随鼠标**：鼠标在卡片里移动时，头部朝那个方向转（±32° / ±15°），离开卡片自动回正。
    - 卡片左上角显示皮肤名，字号和其它组件标题一致；三项交互都能在 ⚙ 设置里单独开关。
  - **多个网站**（3×3，可缩放）：收藏夹式的网址列表，一行一个，点一行或右侧箭头用浏览器打开。
    - 「⋯ → 管理网站…」里可以增删改，每条的图标既可以是本地图片，也可以是图片地址（远程图片下载一次后缓存到插件目录）。
  - **下载自定义文件**（4×3，可缩放）：填一个地址，用启动器自己的 `FileDownloader` 多线程引擎下载到本地。
    - **下载地址**：不写协议会按 `https://` 处理，填完自动补文件名。
    - **保存到**：默认 `<PCL 数据目录>/MyDownload`，点「选择」可以换目录。
    - **文件名**：留空则按地址自动取。
    - **开始下载 / 取消下载**：同一个按钮，下载中显示实时进度（百分比、已下载 / 总大小、速度），完成后可以「打开文件夹」。
- **组件自由组合**：布局按「样式 + 组件」分别保存，增删互不影响；用户删掉的组件不会被自动补回来。
- **添加面板分类**：基础（日历 / 问候 / 最近游玩的世界 / 最近游玩的实例）、收藏内容（单个网站 / 多个网站）、单项快捷入口（实例 / 世界 / 服务器）、PCL 实用功能（下载自定义文件）。
- **布局按样式独立**：花样与极简各自保存一套位置（`layouts.fancy` / `layouts.minimal`），在一种样式里挪动卡片不会影响另一种。每个组件也各自独立，后续新增组件互不干扰。

## 8 档颜色

| 档位 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 颜色 | `#92cfef` | `#76bff4` | `#63acf9` | `#5d95fc` | `#627cfb` | `#6c60f5` | `#763fe9` | `#7d06d6` |

整条色带在 OKLCh 空间里等距取 8 档：明度 0.824 → 0.489 单调下降、彩度 0.077 → 0.257 单调上升、色相 232° → 301° 走短弧，所以相邻两档的感知色差基本相等（ΔE ≈ 0.06），既不会中间发灰，也不会突然跳变。想换色改配置里的 `heatColors` 数组即可。

## 开启 / 关闭

- **关闭**：在启动器「插件管理」里禁用本插件，重启后主页恢复原版。
- 也可以打开 `config.json` 把 `enabled` 改成 `false`。
- 设置 → 启动器选项（个性化）页底部另有一张「高级主页」卡片，可以勾选开关并查看数据位置。

## 数据与配置

`<PCL 数据目录>/AdvancedHomepage/config.json`

```jsonc
{
  "enabled": true,               // 是否启用高级主页
  "template": "calendar",
  "style": "fancy",              // fancy=花样（日历）/ minimal=极简（日期+标语）
  "seeded": ["fancy", "minimal"], // 已初始化过默认组件的样式，删掉的组件不会被自动补回
  "layouts": {                   // 每种样式各自一套布局，互不影响
    "fancy": [
      { "id": "calendar", "col": 4, "row": 0, "colSpan": 3, "rowSpan": 4 },
      { "id": "worlds",   "col": 0, "row": 0, "colSpan": 3, "rowSpan": 3 }  // 最近游玩的世界
    ],
    "minimal": [
      { "id": "minimal", "col": 0, "row": 0, "colSpan": 3, "rowSpan": 4 }
    ]
  },
  "slogans": ["今天的方块，也要一块一块地堆。", "..."],  // 极简模式轮播的标语，随便增删
  "sloganInterval": 6,           // 标语切换间隔（秒）
  "calendar": {
    "weekStart": 1,              // 0=周日 1=周一
    "headerFormat": "yyyy年M月",  // 想显示成「10月31日」可改成 "M月d日"
    "heatColors": ["#92cfef", "..."]
  },
  "history": { "2026-10-31": 3 }, // 日期 -> 启动次数，插件自动维护
  "sites": [                      // 「多个网站」组件展示的收藏网址
    { "id": "site-1a2b3c4d", "name": "Minecraft 官网", "url": "https://www.minecraft.net", "icon": "" }
  ],
  "pins": [                       // 单项快捷入口（实例 / 存档 / 服务器 / 网站）
    { "id": "pin-1a2b3c4d", "kind": "server", "instance": "实例名", "name": "联盟服务器", "target": "play.example.com", "icon": "" }
  ],
  "gridColumns": 9                // 布局所在网格的列数，用于旧配置自动迁移
}
```

日志：`<PCL 数据目录>/AdvancedHomepage/log.txt`

## 兼容性

- 目标启动器：`pclCoreVersion 2026.10.25`（PCL Nex Release win-x64，.NET 10）。
- 注入失败时静默回退原版主页，不会阻止启动器运行（mixin 配置 `required: false`）。

## 安装

把 `高级主页-1.5.1.pclx` 拖入插件页，或解压到 `PCL/Plugins/com.pcln.advancedhomepage/`，重启启动器。

## 已知限制

- 主页内容整块接管，原版主页的「你知道吗」提示卡片会被隐藏。
- 日历热力统计的是「启动」次数（在游戏进程真正拉起时计数），不含启动失败的尝试。
